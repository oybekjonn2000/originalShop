Xavfsizlik

Ma'lumotlar qanchalik xavfsiz?

1
JWT Token — foydalanuvchi kirganida maxsus "kalit" beriladi. Har bir so'rovda shu kalit tekshiriladi.
2
2 darajali ruxsat (RBAC) — oddiy foydalanuvchi faqat o'z ma'lumotlarini ko'radi. Admin sahifalariga faqat admin kira oladi.
3
Ma'lumotlar izolyatsiyasi — har bir foydalanuvchi faqat o'z buyurtmasi, sharhi, sevimlilari va profilini ko'ra oladi.
4
Spring Security — barcha API endpointlar himoyalangan. Ruxsatsiz kirish urinishlari avtomatik bloklangan.

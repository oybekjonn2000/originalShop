Foydalanuvchi

Xaridor uchun imkoniyatlar

🔐 Kirish va Profil

  • JWT Token xavfsizligi ostida tezkor ro'yxatdan o'tish va kirish
  • Shaxsiy ma'lumotlar, parol va avatar rasmini tahrirlash

🔍 Qidiruv va Katalog

  • 3 darajali kategoriya tizimi bo'yicha mahsulotlarni filtrlash
  • Nomlar va brendlar bo'yicha real-vaqt rejimidagi tezkor qidiruv

📦 Mahsulot sahifasi

  • Ko'p rasmli galereya slideri va to'liq tasniflar jadvali
  • 12 oylik muddatli to'lov (kredit/installment) hisoblagichi

🛒 Xarid va Boshqalar

  • Savatga oson qo'shish va buyurtma berish (Fly-to-cart animatsiyasi bilan)
  • Sevimlilar (Wishlist) va mahsulotlarga yulduzli sharh qoldirish

  • Buyurtmalar holatini real-vaqtda boshqarish (Yangi, Yetkazilmoqda, Yakunlandi)
  • Foydalanuvchilar qoldirgan sharhlar va aloqa xabarlarini tahrirlash
Xavfsizlik

Ma'lumotlar va API Xavfsizligi

1
Stateless JWT Token — foydalanuvchi kirganida maxsus shifrlangan kalit beriladi. Har bir API so'rovda ushbu kalit interceptor orqali avtomatik tekshiriladi.
2
Rollar tizimi (RBAC) — oddiy xaridor faqat o'z profiliga kira oladi. Barcha admin sahifalari va yashirin REST API yo'llari faqat `ROLE_ADMIN` huquqiga ega foydalanuvchilarga ochiq.
3
Ma'lumotlar Izolyatsiyasi — xaridorlar faqat shaxsiy buyurtmalari, sharhlari va savatlarini ko'ra olishi ta'minlangan (Ma'lumotlar sizib chiqishining oldi olingan).
